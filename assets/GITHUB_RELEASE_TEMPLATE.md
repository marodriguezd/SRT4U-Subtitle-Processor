# SRT4U Subtitle Processor 💎

## 🚀 Extreme Speed. Modern Design. 100% Local.
**SRT4U** has been upgraded with a professional-grade **Parallel Translation Engine**. It’s not just asynchronous anymore—it now processes subtitles in multiple threads simultaneously, making it up to **80% faster** than previous versions.

### ✨ Key Features:
- **🚀 Parallel Engine (NEW):** Multi-threaded translation core for lightning-fast results.
- **💎 Glass Interface:** Ultra-modern, translucent design optimized for Windows 11.
- **🌍 Smart Translation:** Support for 100+ languages while maintaining exact timing integrity.
- **🧹 Expert Cleaning:** Automatically strips promotional spam, metadata, and social links.
- **🔄 Universal Conversion:** Seamlessly toggle between SRT and VTT formats.

---

### 📦 How to use the executable?
1. Download the `SRT4U.exe` file attached below.
2. Run it (no installation required).
3. Select your subtitle file, pick a language, and watch the parallel engine fly!
